# Data Cleaning, Clustering and Interactive Analysis Using Power BI

## Thiranex Internship – Task 2

### Project Overview

This project focuses on data preprocessing, exploratory analysis, and interactive dashboard development using Microsoft Power BI. The primary objective is to transform raw data into a structured format, identify meaningful patterns, and present analytical insights through interactive visualizations.

The project demonstrates how data cleaning, categorical analysis, and filtering techniques can improve data interpretation and support informed decision-making.

## Objectives

- Import and explore the provided dataset using Power BI.
- Perform data cleaning and preprocessing using Power Query Editor.
- Examine data quality and column distributions.
- Analyze numerical and categorical attributes.
- Develop interactive visualizations to identify patterns.
- Implement slicers for dynamic data exploration.
- Present key statistical insights through dashboard visuals.

## Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query Editor** – Data preprocessing and transformation
- **DAX (Data Analysis Expressions)** – Data calculations and analytical measures
- **Power BI Charts** – Visual representation of data patterns
- **Slicers and Cards** – Interactive filtering and KPI summaries

## Project Implementation

### 1. Data Import and Preparation

The dataset was imported into Microsoft Power BI Desktop for preprocessing and analysis.

The following operations were performed:

- Verified column names and data types.
- Identified missing values and inconsistent records.
- Examined column quality and column distribution.
- Reviewed categorical and numerical variables.
- Prepared the dataset for dashboard development.

### 2. Data Quality Assessment

Power Query Editor was used to evaluate the quality and consistency of the dataset.

The analysis included:

- Checking valid, empty, and error values.
- Reviewing the distribution of column values.
- Identifying potential data inconsistencies.
- Ensuring appropriate data types for analysis.

### 3. Exploratory Data Analysis

Exploratory analysis was conducted to understand the characteristics and distribution of the dataset.

The analysis focused on:

- Comparing records across different categories.
- Understanding gender-based distributions.
- Evaluating numerical attributes using aggregation functions.
- Identifying trends and variations within the data.

### 4. Dashboard Development

An interactive dashboard was designed using multiple Power BI visualizations.

**Categorical Distribution Analysis**

Charts were created to compare the distribution of records across different categories.

**Gender-Based Analysis**

Visualizations were used to examine and compare records based on gender categories.

**Average Value Analysis**

Aggregation functions such as Average were applied to numerical attributes to summarize important characteristics.

**KPI Cards**

Card visuals were incorporated to display important summary metrics and provide a quick overview of the dataset.

### 5. Interactive Filtering

Slicers were implemented to allow users to filter dashboard information dynamically.

These features enable users to:

- Explore records based on selected categories.
- Compare different groups within the dataset.
- Observe changes in dashboard metrics.
- Perform focused analysis without modifying the original dataset.

## Dashboard Features

- Data quality and distribution analysis
- Gender-wise categorical comparisons
- Average value calculations
- Interactive KPI cards
- Dynamic slicer-based filtering
- Clear and structured dashboard layout
- Exploratory data visualization

## Key Learning Outcomes

Through this project, practical knowledge was gained in:

- Importing and preparing datasets in Power BI.
- Using Power Query Editor for data transformation.
- Understanding column quality and distribution.
- Performing exploratory data analysis.
- Applying aggregation functions to numerical data.
- Developing interactive charts and KPI cards.
- Implementing slicers for dynamic analysis.
- Presenting analytical findings through dashboards.

## Conclusion

This project demonstrates the importance of data preparation, exploratory analysis, and interactive visualization in business intelligence.

By utilizing Power BI's data transformation and visualization capabilities, raw information was converted into a structured and interactive analytical dashboard.

The project enhanced practical skills in data preprocessing, statistical analysis, dashboard development, and data-driven decision-making.
